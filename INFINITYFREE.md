# InfinityFree deployment

Site files are at the **repository root** (same level as this file):

```text
index.html
index.php
admin.html
api/
assets/
css/
js/
admin/
uploads/
vehicles/
database.sql
```

## Upload

1. Download the ZIP from GitHub.
2. Unzip `Tesla-main`.
3. Upload the **website files at the root** (index.html, api, assets, …) into InfinityFree **htdocs**.
4. Skip non-site folders if you want (`supabase/`, `lib/`, `.github/`, etc.).

You must end up with `htdocs/index.html` on InfinityFree.
